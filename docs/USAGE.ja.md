## チャット画面

サーバーに入ると自動で接続します。**Y** キー（操作設定で変更できます）でチャット画面を開き、Enter で送信します。

| 操作 | 動作 |
|---|---|
| Enter | 送信 |
| ↑ / ↓ | 送信履歴を呼び出す |
| ホイール / PageUp / PageDown | ログをスクロール |
| Tab | コマンド候補の先頭で補完 |
| Esc | 入力中なら入力を消す。空なら閉じる |

- 画面の上には接続状態・チャンネル・自分の表示名が出ます
- チャット画面を開いている間は、バニラのチャット欄を隠します
- 送信が早すぎて弾かれたときは、入力欄の上に通知が出て、送った文が入力欄に戻ります
- バニラのチャットが使える人は `/mcc 本文` でも送れます

## チャット欄への表示

受信したメッセージはチャット欄にも次の形で表示されます。日時は PC のタイムゾーンです。

```
[MCChat][2026/10/18 12:00] 名前: 本文
```

- 過去ログ（直近 50 件）はチャット画面でだけ見られます。ログイン時にチャット欄へは流しません
- 再接続したときは、切断中に届いた分（最大 10 件）だけチャット欄に流します
- チャット欄に出したくない場合は、設定の `showInChatHud` を `false` にします

## コマンド

チャット画面（または `/mcc /...`）で使えます。`/` を打つと候補が出ます。

| コマンド | 動作 |
|---|---|
| `/jp <文>` | 判定を無視して、まるごとローマ字変換して送る |
| `/japanize [on\|off]` | ローマ字変換のオン・オフ（引数なしで切り替え） |
| `/dict add <語> <置き換え>` | 辞書に登録 |
| `/dict remove <語>` | 辞書から削除 |
| `/dict list` | 辞書の一覧 |
| `/font default` | 標準フォントに戻す |
| `/font uniform` | Unifont にする |
| `/font system <ファイル名> [4〜32]` | PC に入っているフォントを使う |
| `/font size <50〜200>` | チャット画面の文字の大きさ（%） |
| `/font <名前空間:ID>` | リソースパックのフォントを使う |

`/` で始まる文をそのまま送りたいときは `//` と書きます（`//help` → `/help`）。

## ローマ字変換（Japanize）

LunaChat と同じく、ローマ字で打った文を日本語に変換して送ります。

```
ohayougozaimasu!  →  ohayougozaimasu! (おはようございます！)
```

- 既定はオンです。`/japanize` で切り替え、設定の `japanize` に保存されます
- 日本語を含む文は変換しません
- 単語ごとに判定し、ローマ字として読めない単語（`Google`、`OK`）、全部大文字の単語、URL はそのまま残します
- `/jp <文>` は判定を無視してまるごと変換します（`/japanize` がオフでも変換します）
- 漢字への変換には Google の変換 API を使います。**送る文が Google に送られます**。失敗したときはひらがなのまま送ります

## 辞書

ローマ字変換のときに、登録した語を決まった文字に置き換えます（LunaChat の辞書と同じです）。各自の `config/mcchat.json` の `dictionary` に保存されます。

```
/dict add maikura マイクラ     # kyou maikura yarou → kyou maikura yarou (今日マイクラやろう)
/dict remove maikura
/dict list
```

語は大文字・小文字を区別せず、文中のどこにあっても置き換わります（長い語が優先です）。

## フォント

フォントの設定は MCChat の行（チャット画面とチャット欄）にだけ効きます。

### 文字の大きさ

`/font size <50〜200>` でチャット画面の文字の大きさ（%）を変えられます。どのフォントでも効きます。
チャット欄の大きさはバニラの「チャット設定 → 文字の大きさ」に従います。

### PC に入っているフォント

`/font system <ファイル名>` で、`C:\Windows\Fonts` などに入っているフォントを使えます。`/font system ` まで打つと候補が出ます。

```
/font system meiryo
/font system yugothm
/font system bizudgothicr 12    # フォント自体の大きさ（4〜32、既定 11）
```

- Mod がフォントを `resourcepacks/mcchat-system-font` にコピーしたリソースパックを作り、有効にして再読み込みします（数秒かかります）
- `.ttc` はコレクションの最初のフォントが使われます
- フォント自体の大きさはチャット欄にも効きます。設定の `systemFontOversample`（既定 4）を大きくすると、くっきりします
- Adobe Fonts（Creative Cloud）で有効にしたフォントは使えません
- 戻すときは `/font default` です。パックはリソースパック画面から外せます

### リソースパックのフォント

`/font <名前空間:ID>` で使えます。たとえば TTF を使うなら、リソースパックに次の 2 つを入れて `/font mypack:chat` とします。

```
assets/mypack/font/chat.json:
  {"providers": [{"type": "ttf", "file": "mypack:chat.ttf", "size": 11, "oversample": 2, "shift": [0, 0]}]}
assets/mypack/font/chat.ttf
```

存在しない ID を指定すると文字が表示されなくなるので、そのときは `/font default` で戻します。

## 設定ファイル

`config/mcchat.json` はサーバーに入るたびに読み直します。コマンドで変えた設定もここに保存されます。

| 項目 | 既定値 | 内容 |
|---|---|---|
| `serverUrl` | `wss://mcchat.daruks.com/ws` | 接続先 |
| `token` | `""` | 管理者から受け取ったトークン |
| `showInChatHud` | `true` | チャット欄にも表示する |
| `channelOverride` | `""` | 設定すると、シングルプレイを含むどのワールドでもこのチャンネルを使う（テスト用） |
| `japanize` | `true` | ローマ字変換 |
| `dictionary` | `{}` | 辞書 |
| `font` | `""` | フォント ID（空なら標準） |
| `systemFont` | `""` | `/font system` で選んだファイル |
| `systemFontSize` | `11` | PC のフォントの大きさ |
| `systemFontOversample` | `4` | PC のフォントの精細さ |
| `textScale` | `100` | チャット画面の文字の大きさ（%） |
